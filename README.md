# Прогнозування несправностей обладнання у промислових системах

Курсова робота з дисципліни «Інтелектуальний аналіз даних».
Виконав: Цар В.С., група КН-42сп, спеціальність 122 «Комп'ютерні науки».

## Опис

Веб-застосунок на Python (Streamlit), що за показниками роботи технологічного
обладнання прогнозує ймовірність несправності та її найімовірніший тип.

Задача Data Mining — **класифікація**. Основний алгоритм — **випадковий ліс
(Random Forest)**; для порівняння використано дерево рішень, градієнтний бустинг,
логістичну регресію та метод k-найближчих сусідів.

Набір даних — [AI4I 2020 Predictive Maintenance Dataset](https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset)
(UCI Machine Learning Repository, 10 000 записів).

## Можливості

- завантаження та огляд даних, описова статистика;
- оцінювання якості даних (пропуски, дублікати, викиди, суперечливі записи) та очищення;
- формування похідних ознак (різниця температур, механічна потужність);
- кореляційний аналіз і автоматичне вилучення сильно корельованих ознак;
- стандартизація ознак (z-оцінка);
- навчання моделі, оцінювання якості (Accuracy, Precision, Recall, F1, ROC-AUC),
  матриця помилок, ROC-крива, 5-кратна крос-валідація;
- порівняння п'яти алгоритмів класифікації;
- прогноз для нового обладнання (одного або пакетом із CSV) з рекомендаціями;
- інтерпретація: важливість ознак, правила дерева рішень, частота несправностей за інтервалами.

## Структура проєкту

```
├── app.py                 # інтерфейс користувача (Streamlit)
├── src/
│   ├── config.py          # налаштування, назви колонок, підписи
│   ├── data_loader.py     # завантаження набору даних
│   ├── preprocessing.py   # якість даних, очищення, ознаки, кореляція
│   ├── models.py          # навчання, оцінювання, прогноз
│   └── charts.py          # графіки
├── tests/test_pipeline.py # автоматичні тести
├── data/                  # набір даних ai4i2020.csv
├── models/                # збережена навчена модель
└── requirements.txt       # залежності
```

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Застосунок відкриється у браузері за адресою http://localhost:8501.
Під час першого запуску натисніть «Завантажити набір даних з UCI» на головній сторінці.

## Тести

```bash
python -m unittest discover tests -v
```
